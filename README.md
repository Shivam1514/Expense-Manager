## Project Description

AI Expense Manager is a smart financial management application designed to help users track, manage, and analyze their expenses efficiently. The system provides AI-powered financial insights along with graphical visualization of daily, weekly, monthly, and yearly spending patterns.

---

## Key Features

- Expense Tracking System
- AI-Based Financial Assistant
- CSV Bulk Expense Upload
- Expense Export Functionality
- Daily, Weekly, Monthly & Yearly Analysis
- Interactive Charts & Visualization
- Category-Wise Expense Monitoring
- User-Friendly Dashboard
